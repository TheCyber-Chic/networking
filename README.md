<h3>networking</h3>
<p>Hands-on networking projects documenting my learning and practical development in network design, configuration, administration, and troubleshooting.</p>

## <h3>Projects</h3>
- [Small Office Network Design](small-office-network-lab/) - A simulated small office network featuring wired and wireless connectivity, network services, and basic troubleshooting using Cisco Packet Tracer.

-  [VLANs and Inter-VLAN Routing](vlans-and-inter-vlan-routing-lab/) - A departmental network exploring VLAN segmentation, inter-VLAN communication, and centralized network services using Cisco Packet Tracer.

-  [Multi-Site Enterprise Network Design and Implementation](multi-site-enterprise-network-lab/) - A three-site enterprise network connecting Lagos, Abuja, and Port Harcourt, with departmental segmentation, centralized services, wireless access, and basic network security using Cisco Packet Tracer.
