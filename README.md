<h3>networking</h3>
<p>Hands-on networking projects documenting my learning and practical development in network design, configuration, administration, and troubleshooting.</p>

## <h3>Projects</h3>
- [Small Office Network Design](small-office-network-lab/) - A simulated office network demonstrating wired and wireless connectivity, IP addressing, DHCP, DNS, HTTP, and network troubleshooting using Cisco Packet Tracer.
-  [VLANs and Inter-VLAN Routing](vlans-and-inter-vlan-routing-lab/) - A simulated departmental network demonstrating VLAN segmentation, router-on-a-stick inter-VLAN routing, subnetting, centralized DHCP and DNS services, and internal web hosting using Cisco Packet Tracer.
-  [Multi-Site Enterprise Network Design and Implementation](multi-site-enterprise-lab/) - A simulated three-site enterprise network connecting Lagos headquarters with Abuja and Port Harcourt branches. Demonstrates VLAN segmentation, inter-VLAN routing, static routing, centralized DHCP, DNS, and HTTP services, wireless BYOD connectivity, and ACL-based traffic restrictions using Cisco Packet Tracer.
